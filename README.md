# Лабораторна робота Реалізація черги
## Мета роботи
Вивчення принципу роботи зі структурою даних «черга» (FIFO — First In, First Out) у мові програмування C++ за допомогою стандартної бібліотеки шаблонів (STL). Опанування базових операцій із чергою (push, pop, front, back, empty), а також набуття навичок пошуку та обробки елементів черги за заданими критеріями (зокрема, порівняння елементів із першим та останнім елементом колекції).

Реалізовано алгоритми обробки, фільтрації числових і символьних даних за заданими умовами.   Опановано роботу зі структурами (struct) усередині черг для моделювання реальних процесів.
